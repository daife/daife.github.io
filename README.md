# daife · 个人项目作品集

GitHub Pages：<https://daife.github.io/>。静态 HTML/CSS/JS，无前端依赖、无运行时 API 请求。关闭 JavaScript 仍可阅读全部项目、展开说明并访问源码；JavaScript 增强搜索和方向筛选。

## 更新内容

1. 编辑 `projects.json`：项目概要、技术栈、实现亮点、公开状态、相关仓库与固定提交证据。
2. 页面结构在 `templates/index.html`，样式与交互在 `assets/`。
3. 运行 `python3 scripts/build.py` 重新生成 `index.html`，将数据与生成结果一起提交。
4. 本地预览：`python3 -m http.server 8000`，打开 `http://localhost:8000`。

GitHub Pages 从 `main` 分支根目录发布，无需另设构建流程。生成脚本只依赖 Python 标准库。

## 内容口径

本版根据 2026-10-10 的项目材料梳理，于 2026-10-11 更新。41 个展示项目组覆盖 9 个方向；关联客户端、服务端及共享历史合并展示，项目组数不等于仓库数，也不代表全部个人项目。

- 精选项目和其他方向列表合计 41 组，各项目在列表中仅出现一次。
- 源码功能与历史记录可以描述实现；没有可靠运行证据时不添加性能、成功率、用户量或学习收益数字。
- 私有项目只发布编辑后的概要，不复制内部材料，不链接私有源码。
- 开源二次开发保留上游归属，非默认分支贡献链接到相应分支；证据链接采用固定 SHA。
- 原型、课程实验、仿真与科研复现分别标注；提交日期用于探索轨迹，不替代实际投入时间。
- 数据集、笔记、第三方参考和个人贡献待确认的协作仓库不作为独立研发成果堆入作品集。
